Roller derby Tournament Fixture Maker

Paste a WFTDA tournament sanctioning application. RTFM reads the schedule and every team's charter, and makes each game as it is before the first whistle: a statsbook with the IGRF filled in, and a game file for the CRG scoreboard. Add the officials' infopack and the crews come along.

What does it need?
  • The sheets must be shared so anyone with the link can view them. RTFM downloads them as spreadsheets; it never asks Google for anything else.
  • The application's Basic Info tab links each team's charter; the Schedule tab lists the games. Games that say "Winner Game 3" get a team picker.
  • From charters RTFM takes skater numbers, names, pronouns, pronunciation and WUID, never legal names. From infopacks it takes the crews, never contact details.
